# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating, you agree to follow its standards for respectful participation and its enforcement guidelines.

The Code of Conduct applies to project spaces, including issues, pull requests, discussions, and any event where someone represents this project.

## Reporting

Report abusive, harassing, or otherwise unacceptable behavior to the project maintainer, [@evanschleret](https://github.com/evanschleret), through GitHub. Reports will be reviewed promptly and fairly, and reporter privacy will be respected.

For security vulnerabilities, use the private process in [SECURITY.md](SECURITY.md) instead.
