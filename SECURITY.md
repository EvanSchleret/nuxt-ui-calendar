# Security Policy

## Supported versions

Security fixes target the latest published package release. Older package releases are not supported.

| Version | Supported |
| --- | --- |
| Latest published release | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/evanschleret/nuxt-ui-calendar/security/advisories/new). Do not report security issues in public GitHub issues.

The maintainer will review reports, follow up through GitHub, and coordinate a fix and disclosure. Do not include secrets or personal data that are not needed to explain the issue.
